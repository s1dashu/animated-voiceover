# 电影感 3D 动画

## 稳定的视觉语言

- 使用风格化 3D 动画电影的造型与渲染，角色精致但不过度写实，轮廓、比例和表情保持清楚可读。
- 使用哑光材质、手绘表面纹理、克制的高光与细腻胶片颗粒，避免塑料感、游戏 CG 感和照片级真人质感。
- 以低饱和蓝灰、灰绿和中性色为基础，根据场景加入少量暖色或其他强调色。保留电影化明暗层次，但不固定某一种时间、天气或光位。
- 用景深、体积空气和层次化布光建立空间感；这些是可按镜头取舍的手段，不要求每幅画面同时出现。

## 撰写图像 Prompt

1. 先根据当前内容定义主体、动作状态、环境、时代、构图和画面承担的叙事信息，再加入本风格的造型、材质、色彩与光影规则。
2. 具体写出主体和环境分别采用什么材质及表面处理，避免只写“电影感 3D”而让模型自由选择渲染体系。
3. 根据场景重新决定时间、天气、主光方向、冷暖关系、景别和镜头焦段；只保持低饱和、克制、文学性的整体气质，不复用固定的蓝调夜景、浅景深或人物构图。
4. 生成人物参考图时优先锁定身份、轮廓、比例、服装和材质；生成风格参考图时则选择能同时展示角色、环境、远近层次与照明关系的内容专属场景。

## 撰写视频 Prompt

1. 先从旁白和视觉事件推导每镜的主体动作、状态变化和结果，再用可信的重量、惯性、布料、头发、道具与环境反馈体现 3D 动画的物理质感。
2. 根据叙事目的选择静止机位、摇移、跟拍、推拉、环绕、手持感或其他摄影方式。风格只约束影像质感，不预设固定运镜；不得让每镜都缓慢推近、环绕人物或重复同一种景深变化。
3. 允许不同镜头改变场景、时间、天气、景别、光向和强调色，只要角色造型、材质体系、渲染方式及整体色彩克制度保持一致。
4. 使用已确认参考图时，让参考图负责画风一致性；视频 Prompt 仍需为当前片段重新写动作、机位、空间关系、切换和终点，不复刻参考图的构图或把它当作固定首帧。
