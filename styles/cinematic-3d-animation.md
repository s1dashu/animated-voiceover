# 电影感 3D 动画

## 稳定的视觉语言

- 使用明显风格化的 3D 动画电影人物造型。角色采用有意识的非真人比例与概括化结构，头身关系、五官尺度、躯干、四肢和姿态可以偏离真人，但仍要保持可信的骨骼关系、清楚轮廓与可读表情；不得退回照片级演员或普通真人比例。
- 夸张应服务于人物辨识度。先捕捉每个人物最关键的身份特征，例如脸部外轮廓、发型、眉眼关系、鼻口结构、年龄痕迹、体态、惯常姿势或服装剪影，再选择其中少数特征进行放大、压缩、拉长、缩短、变圆或变尖。不要机械地给所有人物套用大眼、长脸、巨大头部、夸张胡须或同一种身材。
- 不同人物使用不同的形状语言和比例节奏，使其仅凭剪影也能区分。写实程度可以统一，但具体夸张点必须随人物身份变化；群像中避免同脸、同头身比和同一套五官模板。
- 使用哑光材质、手绘表面纹理、克制的高光与细腻胶片颗粒，避免塑料感、游戏 CG 感和照片级真人质感。
- 以低饱和蓝灰、灰绿和中性色为基础，根据场景加入少量暖色或其他强调色。保留电影化明暗层次，但不固定某一种时间、天气或光位。
- 用景深、体积空气和层次化布光建立空间感；这些是可按镜头取舍的手段，不要求每幅画面同时出现。

## 撰写图像 Prompt

1. 先根据当前内容定义主体、动作状态、环境、时代、构图和画面承担的叙事信息，再加入本风格的造型、材质、色彩与光影规则。
2. 为每个主要人物先列出少量真正具有辨识度的特征，再明确哪些特征需要选择性夸张、哪些保持克制。用“轮廓更方或更圆、头部相对躯干更大或更小、鼻梁更长、肩线更窄、姿态更前倾”等结构描述表达，不把某个案例的具体五官写成通用模板。
3. 明确要求“风格化、非真人比例的 3D 动画人物”，并写出人物自身的比例与形状语言；同时排除照片级真人、写实演员和普通真人比例。只写“电影感 3D”不足以锁定人物造型。
4. 具体写出主体和环境分别采用什么材质及表面处理，避免让模型自由选择渲染体系。环境可以比人物更接近真实尺度，但必须与人物共享同一套哑光材质、手绘纹理和电影化光影。
5. 根据场景重新决定时间、天气、主光方向、冷暖关系、景别和镜头焦段；只保持低饱和、克制、文学性的整体气质，不复用固定的蓝调夜景、浅景深或人物构图。
6. 生成人物参考图时锁定人物独有的身份特征、外轮廓、头身关系、五官比例、体态、服装剪影和材质。生成风格参考图时选择能同时展示人物造型、环境层次与照明关系的内容专属场景；已有确认参考时，明确它负责人物身份、人物比例还是整体画风。

## 撰写视频 Prompt

1. 先从旁白和视觉事件推导每镜的主体动作、状态变化和结果，再用可信的重量、惯性、布料、头发、道具与环境反馈体现 3D 动画的物理质感。造型可以夸张，但动作仍要让观众理解重心、受力和接触关系。
2. 跨镜头保持每个人物已经确认的非真人头身关系、外轮廓、五官比例、体态与服装剪影，不得在远景、侧脸或激烈动作中逐渐变回写实演员，也不得把不同人物收敛成同一套动画脸。
3. 表演幅度沿用人物自身的形状语言：可以通过眉眼、嘴角、头部倾斜、肩背和手势放大情绪，但只强化该人物已有的关键特征，不临时添加与身份无关的统一大眼或夸张五官。
4. 根据叙事目的选择静止机位、摇移、跟拍、推拉、环绕、手持感或其他摄影方式。风格只约束影像质感，不预设固定运镜；不得让每镜都缓慢推近、环绕人物或重复同一种景深变化。
5. 允许不同镜头改变场景、时间、天气、景别、光向和强调色，只要角色造型、材质体系、渲染方式及整体色彩克制度保持一致。
6. 使用已确认参考图时，明确参考图负责人物身份、人物比例或整体画风；视频 Prompt 仍需为当前片段重新写动作、机位、空间关系、切换和终点，不复刻参考图的构图或把它当作固定首帧。
