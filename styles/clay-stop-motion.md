# 黏土定格动画

## 稳定的视觉语言

- 使用真实手工黏土偶与微缩布景的定格动画观感，保留指纹、压痕、接缝、塑形痕迹和轻微不对称。
- 角色比例可以略显笨拙但要亲切、清楚，环境与道具使用黏土、毛毡、纸张、木片、织物等可辨认的手作材料。
- 使用实景摄影式布光、可感知的微缩尺度和适度景深，避免光滑塑料玩具、无瑕数字 3D 和写实真人材质。
- 色彩保持低饱和、成熟和克制，但具体主色、冷暖关系与光线气氛随内容变化，不固定某一种布景或配色。

## 撰写图像 Prompt

1. 先写当前画面的主体、动作状态、布景、道具、构图和叙事目的，再说明各元素由哪些手作材料制成以及要保留的人工痕迹。
2. 用微缩尺度线索、真实接触阴影、材料边缘和制作痕迹建立定格感，不能只添加“黏土风”标签，也不要把所有物体都处理成同一种光滑橡皮泥。
3. 根据内容重新设计具体、可识别的室内、户外或历史场景，写清视角、景别、光源和色彩关系；不复用固定桌面、舞台或微距构图，也不用抽象布景代替事件。
4. 生成人物参考图时，在纯白背景上并列展示同一黏土角色的正面与背面全身形象，保持相同尺度、服装材料和自然中性站姿；正面锁定角色轮廓与五官塑形，背面锁定后脑、肩背、服装背面和标志性配件，同时保留手作误差，避免不同角色变成同一个模具的换装版本。

## 撰写视频 Prompt

1. 让动作具有逐帧塑形的节奏、可感知的重量和清楚的关键姿态；可以出现轻微停顿、材料压缩或接触形变，但不要给所有动作叠加同一种抖动和顿挫。
2. 优先写清角色怎样触碰、推动、折叠、拆装或改变实体道具，让材料反应服务于当前视觉事件，而不是为了展示风格反复揉捏和变形。
3. 根据叙事选择锁定机位、横移、俯拍、微距、跟随、快速切换或其他拍摄方式。不要把定格动画等同于固定机位，也不要让每段都使用相同的桌面推镜、绕拍或镜头跳动。
4. 转场可以使用硬切、动作匹配、替换动画、布景翻转或其他手作机制，但只在内容需要时采用。每个片段重新设计动作、机位和转场，同时保持黏土材质、手作尺度与逐帧运动质感。
