# 笨拙感手绘动画

## 稳定的视觉语言

- 使用粗糙、歪斜、故意不规则的手绘线条，保留干粉彩、彩铅、稀疏排线、擦痕和粗纸颗粒。
- 造型朴拙、比例略带天真感，但人物身份、姿态、道具和空间关系必须清楚，不能把“笨拙”误解为信息含混。
- 画面以平面化色块和少量层次组成，色彩低饱和、温柔而克制；可以从灰蓝、青绿、赭黄、暖米色及相邻色域中按内容重新配色。
- 保留纸面与笔触的物理感，避免光滑矢量插画、精修数字描线、写实照片和 3D 体积渲染。

## 撰写图像 Prompt

1. 先明确当前画面的主体、姿态、环境、道具、构图和象征关系，再选择适合它们的线条、笔材、纸张、色块和排线方式。
2. 用可见笔触、线条粗细变化、局部出界、擦除痕迹和纸纹建立手作感，同时保持主体轮廓、视觉焦点和前后层次可读。
3. 根据内容改变场景、留白、景别、视角、色彩组合和明暗关系；不默认复用孤独人物、湖边、黄昏或其他示例性构图。
4. 生成人物参考图时固定轮廓、发型、服装色块和标志性道具，不要求每根线完全一致；一致性来自可识别特征和同一套绘画材料，而不是机械复制线稿。

## 撰写视频 Prompt

1. 先设计当前镜头必须完成的可见动作，再选择逐帧姿态变化、轻微线条沸腾、色块位移、纸面擦改、干刷拖影或局部形变等适合该动作的手绘运动方式。
2. “粗糙”不能代替动作描述。明确动作的起点、方向、幅度、速度与终点，让关键姿态清楚；线条抖动和纸纹变化只作为辅助质感，不得成为每镜唯一的运动。
3. 根据叙事选择静止构图、横移、推拉、俯视、主观视角、分层视差、硬切或其他方式。不要让每个片段都重复缩放、横移、画面变形或同一种笔触转场。
4. 允许不同镜头使用新的空间、构图、景别和强调色；只需保持线条、笔材、纸张、造型逻辑和色彩克制度一致。参考图负责画风，不负责规定视频的镜头路径和动作模板。
