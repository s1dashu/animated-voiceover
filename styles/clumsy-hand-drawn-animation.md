# 笨拙感手绘简笔画动画

## 风格定位

像一个不太会画画、但很会观察生活的成年人，用钝铅笔和干粉彩在粗纸上画出的哲学小动画。

## 稳定的视觉语言

- 使用二维极简简笔画与大面积留白。画面不追求完整和精致，只保留表达当前视觉事件所必需的人物、物体与环境线索。
- 线条明显歪斜、断续、抖动且粗细不均，允许重复描线、错误轮廓、局部出界和擦改痕迹；保留钝铅笔、干粉彩、彩铅、稀疏排线与粗纸颗粒。
- 人物头身比例故意不准确，四肢细长、弯曲，姿势略显僵硬笨拙。五官只用点、短线和简单弧线表达，但身份、姿态与情绪必须清楚可读。
- 场景使用少量歪线和扁平色块概括，只画必要的桌椅、建筑、树木、道路或其他内容相关物体，不追求透视严谨和背景完整。
- 以低饱和灰蓝、青绿、褪色赭黄、暖米色及相邻色域为基础，按内容重新组合主色与强调色。用色块、纸色和稀疏排线表达明暗，不使用写实的三维光影塑形。
- 整体保持成熟、克制、略带忧郁的成人观察感；朴拙来自有意识的表达选择，不走儿童涂鸦、可爱卡通、卖萌或幼儿绘本路线。

## 撰写图像 Prompt

1. 先明确当前画面要讲清的具体事件、人物动作和因果关系，再选择必要的主体、道具和环境线索。每张图重新设计可识别的场景与构图，不把任何示例人物或场景当作默认模板。
2. 不只写“粗糙手绘”或“简笔画”。明确人物由极少量歪斜线条组成，并指定断线、重复描线、错误轮廓、擦改痕迹、钝铅笔、干粉彩和彩铅等可见特征。
3. 生成人物参考图时固定头身关系、轮廓、发型、服装色块和标志性道具，同时保留故意不准的比例与手绘误差。不要为了身份一致而把人物修成精致、标准的人体。
4. 根据内容改变留白、视角、景别、主体位置、色彩组合和明暗关系。背景只保留理解画面所需的物体，不补齐装饰性细节，也不使用复杂透视和真实光影提升“完成度”。
5. 检查候选参考图是否第一眼就有明显的“不会画”和“简笔画”感觉。如果只是给完整、漂亮的商业插画叠加纸纹、粉彩或粗线，仍视为风格失败并重新生成。

## 撰写视频 Prompt

1. 先设计当前镜头必须完成的可见动作，再写清动作的起点、方向、幅度、速度和终点。人物运动可以略显僵硬、迟疑和笨拙，但关键姿态与因果关系必须清楚。
2. 使用轻微线条沸腾、逐帧重画、轮廓误差、色块小幅漂移或纸面擦改体现手绘动画质感。它们只作为辅助变化，不得代替主体动作，也不要让所有元素持续同幅度抖动。
3. 根据内容自由安排单人、多人、道具和完整环境，不设固定数量限制。像动画电影分镜一样写清所有元素的初始位置、前后层级、动作顺序、运动路径、相互作用、背景变化和最终状态；粗糙简笔画风格不能成为省略关键调度信息的理由。
4. 根据当前视觉事件选择静止构图、横移、推拉、俯视、主观视角、分层视差、硬切或其他摄影方式。使用运镜时，逐项写清摄影机起点、屏幕移动方向、与主体的相对位置、阶段衔接和终点。不要让每个片段重复同一种缩放、横移、变形、擦除或笔触转场。
5. 允许不同镜头采用新的空间、构图、景别、主色和运动方式；只保持简笔造型、粗糙线条、纸面材料、低饱和配色与成人气质一致。参考图负责画风，不负责规定镜头路径。
6. 不用卡片、路牌、墙面、气泡或漂浮标签上的小字解释抽象概念；改用发生在可识别场景中的具体事件、人物动作、接触反馈和直接结果表达，姿态与物体关系只作辅助。只有用户明确要求画内文字时才写入。

## 明确排除

- 干净流畅的矢量线条、精致完整的商业插画、细腻水彩晕染和过度丰富的背景细节。
- 日系动漫人物、可爱大头比例、儿童绘本、幼儿涂鸦和卖萌表情。
- 写实人体、复杂五官、标准精确透视、三维渲染与真实光影。
