# 清爽白色圆身 Storytime 动画

## 风格定位

使用白色圆身卡通人物、粗黑干净轮廓和有限鲜明色块构成的二维 Storytime Animation。人物造型简洁而有成年人的喜剧表现力，环境比人物更具体，但始终保持同一套清爽平面动画语言。

## 稳定的视觉语言

- 人物可以白色圆身为主要识别语言，也可以按用户确认的角色设计加入肤色、服装或更完整的身体结构。头身比例从接近常规卡通比例到明显大头小身均可，优先服务年龄感、人物性格和表演，不把某一种比例设为硬性模板。
- 轮廓使用粗而顺滑、连续、紧实的黑线，边缘整齐锐利，线宽整体稳定。只保留辨认姿势和结构所需的内部线，不使用铅笔、蜡笔、粉笔、水彩、纸纹、毛边、草稿线或重复描线。
- 五官可以从点状眼睛和极简口型，到结构更完整但仍卡通化的眉眼鼻口。表情通过眉眼、嘴形、头部倾斜、身体重心和手势共同完成，不要求所有角色共享同一张极简脸。
- 手脚可以使用圆形、手套形或适度简化的卡通手形；细节程度服从所选人物设计，只避免与整体画风割裂的写实解剖。
- 头发、衣服和关键道具可以使用平涂、相邻色块、少量高光、柔和渐变和简单明暗。保持二维卡通的清楚大轮廓即可，不把“绝对无渐变、绝对无阴影”作为稳定身份的前提。
- 环境可以包含房间、学校、办公室、街道、商店或其他完整地点，并比人物拥有更多家具、建筑和生活道具细节；所有环境仍使用干净黑线、平面色块和简化透视，不能突然转成照片、写实背景或 3D 场景。
- 整体气质轻松、直接、机敏且适合自嘲。造型可以夸张，但不能幼儿化、低龄绘本化或变成只有空白背景与符号的极简贴纸动画。

## 撰写图像 Prompt

1. 先与用户确认角色年龄、体型、头身比例、发型轮廓、服装、表情和气质，再选择保留多少白色圆身语言；不把任何既有人物的比例、五官、发型或服装设为风格默认值。
2. 生成人物参考图时，锁定大轮廓、头身关系、点状五官位置、发型大色块、服装配色和圆手圆脚。不同角色通过轮廓、体型、发型、服装与姿态区分，不只依靠换色。
3. 需要场景时，明确地点的空间结构和能说明生活状态的关键道具。环境细节多于人物结构细节，但必须用同一线条粗细、平面色彩和简化透视组织。
4. 检查人物是否仍有青年或成年人的身份感与喜剧表演空间。如果变成婴儿比例、幼儿绘本吉祥物、火柴人、纯白无特征人偶或写实卡通肖像，应重新生成。

## 撰写视频 Prompt

1. 让讲述者通过清楚的口型、眉眼变化、头部倾斜、重心转移和简化圆手手势完成镜头内表演；动作幅度要可读，但不让人物持续弹跳、挥手或过度挤眉弄眼。
2. 在讲述画面中保持人物与观众的直接关系，同时让环境道具承担地点、职业、时间和生活状态信息。人物不应只是站在空背景前念稿。
3. 在事件重现中使用具体互动、过肩镜头、反应镜头和可见后果。重现人物与讲述者使用同一造型和渲染体系，但不得复制关键人物外貌制造分身。
4. 背景可以比人物更密集，仍需通过清楚轮廓、前中后景和有限色块保持可读；不以小字、图标阵列或漂浮标签替代事件。
5. 镜头之间默认直接硬切。新地点或回忆从完整的新场景开始，不写擦除、变形、融化或装饰性换景；只有长时间动作、打斗或连续调度本身是创作重点时，才设计不中断的长镜头。

## 明确排除

- 蜡笔、铅笔、粉笔、水彩、粗纸纹、毛边、断线、重复草稿线和模糊轮廓。
- 与角色设定不一致的写实解剖、照片式人物、三维体积与复杂电影光影。
- 用户未选择的幼儿化气质、标准吉祥物换色和无法体现既定年龄与性格的空白表情。
- 过度空白的贴纸画面、只有抽象符号的背景，以及与人物画风割裂的复杂写实环境。
- 擦除、形变、融化、线条延伸、颜色接力等装饰性转场。
