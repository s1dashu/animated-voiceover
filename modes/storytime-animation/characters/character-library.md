# Storytime 人物形象库

这个目录只服务 Storytime Animation，用于保存用户明确确认、希望在后续作品中继续选择或改编的常用讲述者形象。人物形象库与 `styles/` 分开：style 决定视觉语言，人物卡决定具体角色身份，两者可以重新组合。

## 使用流程

1. 开始 Storytime 人物规划时，先询问用户沿用已有形象、从本库选择，还是共同设计新形象；不设置默认人物。
2. 从本库选择时，展示候选图、简短角色说明和验证状态，等待用户确认。允许在原形象上修改发型、服装、年龄感、体型和配色，修改后另存新版本。
3. 新建时，通过对话确认年龄感、体型与比例、脸部与发型、服装、线条与色彩、人物气质。先生成少量候选，不强制纯白背景、正反面同图或固定平涂方式。
4. 用户确认后，询问是否保存到人物形象库。只有用户明确同意时才新增目录，至少保存 `reference.png` 和 `character.md`。
5. `character.md` 记录稳定外观、允许变化、生成说明、来源、确认状态及实际作品验证状态。私人路径、平台节点和账号信息留在宿主项目，不写入公开人物卡。
6. 删除或替换人物时同步修改本清单，不让失效图片继续被推荐。
