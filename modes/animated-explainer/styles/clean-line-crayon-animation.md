# 清爽线描蜡笔动画

## 风格定位

以清楚的深色手绘线条组织画面，再用明快蜡笔色块填充的二维动画。它兼顾简洁、萌感和图形识别度，既能表现角色，也适合建筑、车辆、物件和完整环境。

## 稳定的视觉语言

- 使用深蓝、蓝黑或深棕的手绘轮廓线，线条总体清楚有力，但保留轻微抖动、断墨、粗细变化和不完全闭合，避免变成机械矢量描边。
- 用圆形、方形、梯形、弧线和短直线概括人物、动物、建筑、车辆与道具；几何关系简洁，允许透视略显天真，但前后层次和行动路径必须易读。
- 色彩采用少量明快、低复杂度的蜡笔或彩铅平面色块，允许笔触纹理、纸色透出和边缘轻微错位；具体主色与冷暖关系随内容改变。
- 构图保持清爽、有秩序和适度留白，但不限制主体、动作、道具或视觉中心的数量。多人、复杂环境和并行动作都应通过明确的前后层级、空间关系与行动路径保持可读。
- 萌感来自几何比例、轻微歪斜、物体间的尺度关系和友善动作，不要求所有物件拟人化，也不把人物面部作为唯一情绪来源。
- 画面可以表现城市、自然、室内、机械、交通、群体关系和具体事件，不固定任何历史示例中的题材与构图。

## 撰写图像 Prompt

1. 先写当前场景的视觉中心、空间结构、动作路径和必要环境，再说明哪些元素用圆形、方形、弧线或短直线概括。
2. 明确轮廓采用深色手绘线描，并指定轻微抖动、断墨和粗细变化；同时说明蜡笔色块的有限配色、纸色透出和边缘错位，避免模型生成干净矢量图。
3. 表现建筑、车辆或复杂物件时，保留最能识别身份和运动方向的结构，删去装饰性机械细节、真实材质和精确工程透视。
4. 表现人物或动物时，用简洁体块区分体型、服装、姿态和身份；五官保持克制，不能依赖动漫大眼或统一圆脸制造可爱感。
5. 检查画面是否既简洁又有完整空间。如果场景被压缩成孤立图标、信息图标阵列或上下分格画面，应重新明确单一连续场景与构图关系。

## 撰写视频 Prompt

1. 让线描主体沿清楚路径移动、转向、碰撞、连接、拆分或改变排列；每镜必须有可见起点和终点，不能只让色块轻微闪动。
2. 使用轻微线条沸腾、轮廓逐帧重画和蜡笔色块小幅错位保持手绘感，但控制幅度，避免影响几何轮廓和空间可读性。
3. 环境镜头优先利用道路、轨道、桥梁、门窗、桌面、树木或其他结构引导运动；车辆、物件和建筑部件也可以成为主要动作主体。
4. 根据内容使用俯视、平视、横移、跟随、分层视差、复合运镜、快速切换或静止构图。像动画电影分镜一样逐项写清初始构图、主体调度、动作阶段、摄影机起点、屏幕移动方向、与主体的相对位置、阶段衔接和最终构图。不要把清爽图形风格固定成同一种俯视模型景观或缓慢横移。
5. 镜头之间默认直接硬切，不用形状匹配、颜色接力、线条延伸或擦除效果包装切换。只有连续长镜头本身承担明确叙事职责时，才设计不中断的动作与摄影机调度。
6. 不用卡片、路牌、墙面、气泡或漂浮标签上的小字解释抽象概念；改用发生在可识别场景中的具体事件、主体动作、接触反馈和直接结果表达，物体位置与颜色只作辅助。只有用户明确要求画内文字时才写入。

## 明确排除

- 完全笔直、统一线宽的矢量描边，企业信息图标、UI 图标和无纸面痕迹的扁平插画。
- 精确建筑透视、真实机械结构、材质渲染、体积光和三维微缩模型质感。
- 日系动漫人物、复杂五官、过度拟人化，以及靠固定笑脸或腮红制造的单一萌感。
