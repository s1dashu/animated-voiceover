# 柔和彩铅萌趣动画

## 风格定位

用柔软铅笔、彩铅和粗蜡笔在温暖纸面上画出的二维萌趣动画。造型圆润、动作亲切，保留手工涂画的不均匀感，同时确保人物、动物、物体和环境都清楚可读。

## 稳定的视觉语言

- 使用纯二维手绘造型，以圆、椭圆、豆形、三角和少量短线构成人物、动物、物体与环境；比例可以天真夸张，但身份、动作方向和空间关系必须明确。
- 轮廓使用柔软、略微断续和轻微抖动的铅笔线或彩铅线，不追求统一线宽；保留重复描线、纸面摩擦和局部线条变淡。
- 色彩使用松散彩铅与粗蜡笔平涂，允许纸色透出、涂色不完全覆盖轮廓以及少量出界；不使用光滑数字渐变或写实体积塑形。
- 配色保持柔和、低对比和亲切，可按内容重新组合暖红、奶油黄、草木绿、天空蓝、淡紫、暖棕及其他相邻色，不固定某组角色或场景配色。
- 萌感主要来自圆润比例、笨拙姿态、协作关系和动作结果，不依赖大眼、腮红、幼儿服饰或固定吉祥物造型。
- 场景保留理解动作所需的环境层次，可以表现多人互动、动物群体、室内空间、建筑、交通工具或自然环境；不把极简误解为所有主体都站在空白背景中。

## 撰写图像 Prompt

1. 先定义当前画面要表达的动作、关系和环境，再决定主体数量；允许根据内容使用单人、多人、动物、物件或完整场景，不把某类圆头小人作为默认模板。
2. 明确写出主体由哪些简单几何形状构成，以及铅笔轮廓、彩铅或蜡笔平涂、纸色透出和轻微出界等手工特征，避免只写“可爱手绘”。
3. 生成人物或动物参考图时锁定轮廓、比例、服装或身体色块、五官位置和标志性配件；不同角色应在体型、姿态和形状语言上可区分，不能只换颜色。
4. 根据内容重新设计构图、景别、留白、环境密度与主色。群体动作要清楚展示谁在推动、拉动、递交、追赶或配合，不能被装饰性背景淹没。
5. 检查画面是否仍具有明显的手工涂画感。如果只是精致儿童商业插画叠加纸纹，或角色变成光滑标准化吉祥物，应重新生成。

## 撰写视频 Prompt

1. 为每个镜头写清主体动作的起点、方向、幅度和终点，让圆润角色表现出轻微笨拙、可读的重量转移与接触反馈。
2. 使用轻微逐帧重画、轮廓游移、彩铅线深浅变化和蜡笔色块小幅漂移体现手绘动画感；这些变化只辅助主体动作，不让整幅画面持续同频抖动。
3. 根据内容自由安排单人、多人、动物、道具和完整环境，不设固定数量限制。像动画电影分镜一样写清各主体的初始位置、动作先后或同步关系、运动路径、接触反馈、环境响应与最终构图。
4. 根据叙事选择静止构图、横移、跟随、俯视、推拉、分层视差或复合运镜，并逐项写清摄影机起点、屏幕移动方向、与主体的相对位置、阶段衔接和终点。镜头之间默认直接硬切，不写蜡笔擦除或其他装饰性转场；只有连续长镜头本身承担明确叙事职责时才不中断。
5. 环境镜头可以让风、云、水、车辆、建筑部件或纸面色块参与运动，同时保持二维平面、柔和配色和清楚的空间关系。
6. 不用卡片、路牌、墙面、气泡或漂浮标签上的小字解释抽象概念；改用发生在可识别场景中的具体事件、主体动作、接触反馈和直接结果表达，物体关系与颜色只作辅助。只有用户明确要求画内文字时才写入。

## 明确排除

- 干净统一的矢量线、数字渐变、写实光影、照片质感与三维渲染。
- 日系动漫大眼、过度腮红、幼儿绘本装饰堆砌和标准化吉祥物换色。
- 只有纸纹或蜡笔滤镜、但造型和构图仍然精致复杂的商业插画。
