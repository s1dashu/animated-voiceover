# Animated Report

## 当前状态

本 Mode 已完成核心定义，但尚未建立或验证完整的端到端制作流程。当前可用于选题、资料架构、讲稿、素材清单和视觉规划；不得直接声称 skill 已能完成包含授权现实素材、数据图表和编辑合成的完整 Animated Report。

## 核心目标

面向财经、政治、经济、金融、科技产业及其他现实议题，用动画组织分析，并大量混合真人实拍、B-roll、新闻或历史影像、照片、地图、文字、数据图表与信息图形。用可追溯资料支撑对现实事件、趋势、利益关系和可能影响的解释。

## 与 Animated Explainer 的边界

- 如果视频能主要依靠完整旁白与原创动画解释一个相对稳定的概念，使用 [Animated Explainer](../animated-explainer/workflow.md)。
- 如果结论主要依赖新近事件、现实影像、多来源证据、数据、地图和时间线，使用本 Mode。

## 待建立的专属能力

完整实现前至少需要验证：

1. 时效性研究、来源分级、事实核查、观点分离和更正机制。
2. 数据口径、图表设计、地图、时间线和画内文字可读性规则。
3. 真人实拍、新闻影像、照片、文献与 B-roll 的授权、署名、本地落盘和素材溯源。
4. 原创动画、现实素材、图表和字幕的编辑时间线与合成流程。
5. 将论点、证据、旁白、画面素材和最终时码建立可追踪对应。

上述能力没有完成前，不得把 Animated Explainer 的纯动画分片生成流程直接当作本 Mode 的完整执行方案。
