# Visual Journalism 研究与证据指南

## 研究目标

研究不是为既定结论寻找装饰性材料，而是建立一条可追溯的论证链。先确定能被证据回答的问题，再决定结论强度和画面形式。

## 来源优先级

按议题适用性优先使用：

1. 原始文件、官方数据、法律与监管文本、公司披露、论文和一手记录。
2. 有明确方法、作者和引用链的权威机构、学术组织与专业数据库。
3. 有现场采访、文件或多方核实的高质量新闻报道。
4. 具名专家分析，用于解释而不是替代事实来源。
5. 社交媒体、聚合页面和匿名内容只作为线索；未完成独立核验前不得进入旁白事实层。

不要用来源数量掩盖同源转述。多个页面都引用同一份未经核实材料时，只算一条证据。

## 证据账本

为每个会影响结论的主张记录：

| 字段 | 要求 |
| --- | --- |
| `claim_id` | 稳定编号，供旁白和分镜引用 |
| 主张 | 使用完整、可判断真假的句子 |
| 类型 | 事实、分析、预测或价值判断 |
| 来源 | 标题、作者或机构及可访问地址 |
| 发布／更新日期 | 同时记录事件发生时间，避免混淆 |
| 取证位置 | 页码、表格、段落、时间码或数据字段 |
| 核验状态 | 已核验、存在冲突、证据不足或待更新 |
| 视觉证据 | 实拍、文件、地图、图表、动画或无直接画面 |
| 授权状态 | 可用、需署名、需许可、仅供研究或未知 |
| 备注 | 定义、样本限制、替代解释和风险 |

精确数字必须追溯到原始表格或明确引用位置。找不到原始来源时，降低表述精度并说明限制，不复制二手报道中的精确数字冒充已核验数据。

## 事实截止时间与版本

- 在选题简报顶部记录事实截止时间和时区。
- 对政策、战争、市场、公司与科技议题，确认来源在截止时间前仍有效，并记录后续可能改变结论的观察点。
- 同一指标存在修订值时说明采用哪个版本；不同来源使用不同定义、币种、价格口径或时间区间时不得直接比较。
- 地图、行政边界、公司名称、人物职务和联盟关系必须匹配叙事发生时间。

## 论证强度

- **事实**：来源直接支持，可以明确陈述。
- **分析**：由多条事实推导，说明推理链和替代解释。
- **预测**：说明条件、时间范围与可能使预测失效的事件。
- **价值判断**：明确这是评价，不用数据图表伪装为客观事实。

发现可靠反证时更新结论或缩小主张。无法解决的来源冲突必须进入旁白限制、视觉不确定性或最终说明，不能隐藏。

## 视觉证据与授权

- 真实现场、人物、文件和档案素材必须记录来源与使用条件；许可未知时停止下载或使用。
- 新闻截图只截取论点需要的部分，并保留媒体名、日期和必要上下文；不得拼接成来源并未表达的意思。
- 生成的纪录片式画面不是事实证据。它只能用于重建、示意、背景或无法直接拍摄的过程，并在可能误认时明确标注或披露。
- 对真实人物的生成重建不得捏造言行、表情或现场。缺少可靠视觉材料时，优先使用地点、物件、文件、时间线或抽象机制。
- 数据图表保存数据来源、处理步骤、单位、筛选条件和最终使用值；不得仅保存导出的图片。

## 研究完成条件

只有在以下条件同时满足后，才开始正式旁白与分镜：

- 核心结论有足够证据支持，反证和限制已经处理。
- 每个重要数字、引语、地图关系和因果判断都能回到具体来源位置。
- 已确认哪些画面是真实证据、哪些是解释性示意、哪些需要披露。
- 已建立可行的授权与署名方案。
- 仍缺失的信息不会让视频当前结论具有误导性。
