# 现代编辑部 Visual Journalism

## 验证状态

这是基于公开 Visual Journalism 方法研究整理的首轮候选 style，尚未通过本 skill 的完整样片验证。使用时必须把它标记为候选，不得声称其模型表现、镜头节奏、文字能力或跨片一致性已经稳定；样片经用户确认后再更新状态和规则。

## 风格定位

将可信纪录片影像、档案材料、空间地图、动态图表和编辑部式标注组织成清楚、克制、有现实重量的视觉报道。视觉层服务论证与证据阅读，不模仿任何单一媒体品牌，也不把军事界面、新闻演播室或科技 HUD 当作通用模板。

## 稳定的视觉语言

- 以真实世界的材质、地点和光线建立可信度；生成的实拍感镜头保持自然镜头、真实空间、适度现场噪点和观察者距离，避免商业广告的精致摆拍。
- 使用编辑部拼贴语言组织照片、档案、文件和地图：清楚裁切、有限边框、局部放大、下划线、框选和单一重点高亮。所有标注必须承担阅读顺序或来源职责。
- 基础色保持中性和克制，可在暖白或浅灰纸面、石墨黑或深灰信息底之间选择。每个作品根据议题选择一至两种强调色，用于同一语义类别，不固定复刻某个品牌色。
- 地图既可使用平面编辑图形，也可使用轻度立体地形和卫星质感。视角服从空间问题；不把所有议题统一做成军事沙盘。
- 图表使用清楚的形状、有限颜色和充足留白。视觉层级依次是当前结论、关键比较、必要坐标与来源，不展示无关装饰网格和密集仪表盘。
- 文字采用功能性无衬线排版，标题、数字、标签和来源层级明确。高密度正文、精确数字和地图标签由后期可控图形层完成，不以模型伪文字制造信息丰富感。
- 允许轻微纸张、扫描、胶片、打印或屏幕质感，但强度必须克制；质感只用于区分媒介与时间，不覆盖证据内容。
- 整体气质清醒、直接、调查性和有现实重量。可根据文化、科学或生活议题增加温度与轻快感，不把严肃低饱和设为所有主题的唯一情绪。

## 撰写图像 Prompt

1. 先写画面承担的证据、定位、机制、规模、后果或不确定性职责，再决定实拍、档案、地图、图表或插画媒介。
2. 生成实拍感画面时明确地点类型、时间、主体行为、观察距离、镜头焦段倾向、自然光线和现场材质；避免只写“电影感新闻摄影”。
3. 需要档案或文件界面时，把真实材料保留给后期合成；模型只生成不含伪文字的环境底层、桌面、屏幕光或中性框架。
4. 需要地图或图表时，先生成视觉底层与构图占位，再把准确边界、数据、文字、单位和来源列为独立图形层。
5. 根据作品内容选择中性底色和强调色，并为同一种语义保持一致配色；不默认使用警报红、军用绿或荧光黄。

## 撰写视频 Prompt

1. 让运动逐步揭示信息：先建立背景或基准，再加入当前对象与变化，最后让关键关系稳定可读。运动完成后为结论保留阅读时间。
2. 在现实尺度与结构尺度之间切换：用现场、人物或物件呈现地面后果，用地图、图表或机制动画解释其背后的关系。
3. 对照片、文件和档案使用克制推近、平移、裁切、框选或局部高亮；不让所有材料漂浮在三维空间中旋转。
4. 对地图使用平移、推进、俯仰、路径展开和范围高亮；运镜结束位置必须强化方向、距离或控制关系，不追求无意义的大幅环绕。
5. 对图表使用增长、下跌、聚合、拆分、对比和终点锁定。准确文字和数字在后期叠加时，生成层要预留稳定、干净、对比足够的版面区域。
6. 不同素材之间默认硬切或使用同一对象、方向和构图形成自然匹配；不写故障、扫描、融化和 HUD 擦除等装饰性转场。

## 明确排除

- 无来源的伪新闻网页、伪报告、伪引语、伪地图与伪数据。
- 无关城市航拍、握手、键盘、服务器和商务人物等素材库式填充。
- 全片统一军事沙盘、暗黑情报室、新闻演播室或科幻 HUD，而不考虑具体议题。
- 密集小字、复杂表格、不可读仪表盘和持续运动中的关键数字。
- 为了动感改变曲线、比例、边界、路线或对象之间的真实关系。
- 过度光滑、充满镜头光晕和品牌宣传感的企业广告质感。
- 把生成的实拍感镜头当作真实现场证据，或省略必要的模拟与重建披露。
