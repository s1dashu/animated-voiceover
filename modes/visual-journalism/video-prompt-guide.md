# Visual Journalism 视频 Prompt 指南

## 核心原则

先确定镜头的信息职责和证据边界，再写视觉形式。生成模型负责它能够可靠生成的场景、物体、动作、摄影和低密度解释性变化；精确文字、数据、地图边界、图表刻度和来源信息默认交给后期可控图形层。

## 片段规划格式

编写 Prompt 前为每个片段列明：

1. **片段唯一论点**：观众看完后应理解的一句话。
2. **对应证据**：引用证据账本 `claim_id`；没有直接证据时标明这是分析、重建或示意。
3. **镜头职责**：证据、定位、机制、规模、后果或不确定性。
4. **素材类型**：授权实拍／档案、生成实拍感镜头、地图、图表、文件、解释性动画、主持人或专家。
5. **生成层**：模型必须产生的主体、环境、动作、构图和运动。
6. **可控图形层**：后期加入的准确文字、数字、单位、来源、边界、坐标轴和高亮。
7. **披露要求**：是否需要标注模拟、重建、示意或 AI 生成。

## 素材类型

### 纪录片实拍与生成的实拍感镜头

- 使用与论点直接相关的地点、人物工作现场、设备、街道、企业、工厂、市场或公共空间。
- 写清地点类型、时间、天气、空间结构、可见行为和观察距离，避免只写“新闻纪录片镜头”。
- 保持真实光学镜头、自然材质、可信空间和现场声音逻辑；不做成企业宣传片、旅游广告或无关城市空镜。
- 生成镜头不得冒充真实事件证据。需要呈现具体真实事件时，优先使用已授权素材；只能重建时明确限制内容并计划披露。

### 档案、文件与网页

- 已有真实材料时使用原素材并在后期做裁切、推近、框选和高亮，不要求模型重画。
- 只展示支持当前论点的必要区域，同时保留能判断来源、日期和上下文的信息。
- 不让模型自由生成新闻标题、法律条文、报告段落、网站界面、股票代码或引用文本。

### 地图

- 先写地图承担的空间问题，再写视角、范围、起点、终点、高亮顺序和结束状态。
- 使用渐进揭示：基础地理层先稳定出现，再按旁白加入地点、路线、边界、范围或人物关系。
- 相机可平移、推进、俯仰或沿地表移动，但移动必须帮助理解距离与方向。准确数字和标签稳定后停止大幅运镜。
- 精确边界、地名与路线无法由模型保证时，生成无标注的地形或环境底层，在后期叠加核验过的矢量图形。

### 图表与数字

- 每个图表只回答一个比较或变化问题。先建立轴或基准，再显示变化，最后锁定关键点与数值。
- 曲线、柱形、面积、比例和计数必须在运动中保持语义一致；不能为了动感改变数值关系。
- 数字、日期、单位、刻度和来源默认列为可控图形层。只有测试模型少量大字能力时，才把已经核实的文本逐项列入生成 Prompt，并在输出后逐字检查。
- 实拍背景与图表合成时，可以局部压暗、轻微模糊或使用半透明分隔层，但不得遮蔽现实信息或降低数字可读性。

### 解释性动画

- 用于制度、产业链、资金流、技术机制、历史变化和其他无法直接拍摄的关系。
- 具体写出初始状态、对象身份、可见变化、相互作用、结果和结束构图；不以漂浮图标和无意义连线代替机制。
- 动画应说明旁白没有直接说清的空间或因果关系，而不是逐字重复旁白。

## 运动与剪辑

- 使用运动规定阅读顺序：出现、聚合、分离、比较、下跌、扩散、路径推进和终点锁定都必须对应真实语义。
- 在结构概览与地面现实之间切换。地图或图表建立模型后，及时回到人物、地点或物件，避免长时间停留在抽象界面。
- 不要求所有素材类型出现在每个片段。相邻镜头默认直接硬切；只在空间或动作连续性本身承担解释职责时使用连续调度。
- 不把快速缩放、扫描线、故障、HUD、旋转地球或持续推镜作为默认“新闻感”效果。

## Prompt 自检

提交前逐项检查：

- 每镜是否只有一个主要信息职责，且与片段论点一致。
- 真实素材、生成重建和解释性示意是否被明确区分。
- 所有精确文字、数字、单位、日期、地图和图表是否有核验与合成方案。
- 模型是否被要求生成它无法可靠完成的密集排版或事实细节。
- 运动是否改变或模糊了数据与空间关系。
- 实拍感镜头是否具体、可信并与论点直接相关，而非广告式填充。
- 镜头的初始构图、可见变化、相机运动、结束状态与切镜条件是否足够明确。

任一项失败时先修正论点、素材计划或合成边界，再修改 Prompt；不要用更多风格词掩盖信息设计问题。
