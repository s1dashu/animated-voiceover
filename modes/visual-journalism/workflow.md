# Visual Journalism

## 当前状态

本 Mode 用于财经、时政、产业和其他现实议题，以可核查证据、现实素材和明确论点驱动叙事，混合纪录片实拍、档案材料、地图、数据图表与解释性动画。当前工作流来自首轮方法研究，尚未完成资料采集、授权、生成、图形合成、音色和剪辑的端到端实作验证。不得声称流程或候选 style 已经成熟。

## Mode 边界

- 当结论依赖正在发生或仍具现实影响的事件、数据、政策、公司、产业、地点与多来源证据时，使用 Visual Journalism。
- 当任务只需解释一个稳定概念、人物思想或历史知识，不依赖时效性证据与现实素材时，使用 Animated Explainer。
- Visual Journalism 不是“新闻感画风”。核心是让每个重要事实、因果关系和判断都能追溯到来源，并让画面承担证据、定位、解释、比较、后果或不确定性职责。
- 观点可以鲜明，但必须区分已证实事实、基于证据的分析、预测与价值判断，不把推断包装成事实。

## 开始任务前必须读取

1. 研究、事实核查或素材规划：完整读取[研究与证据指南](research-and-evidence-guide.md)。
2. 编写分镜或视频 Prompt：完整读取[Visual Journalism 视频 Prompt 指南](video-prompt-guide.md)、选定的当前 Mode style、[共享视频生成 Prompt 指南](../../references/video-generation-prompt-guide.md)及目标模型指南。
3. 选择或建立音色：完整读取[内置音色库](../../references/reference-asset-library.md)和[音色参考指南](../../references/voice-reference-guide.md)。

## 核心交付物

在进入生成前，至少形成以下可检查内容。草稿默认先在对话中迭代；用户确认后再按宿主项目约定保存。

1. **选题简报**：核心问题、受众需要理解的结论、事实截止时间、地域与时间范围。
2. **论证图**：主张、关键依据、因果链、反例或限制、仍不确定的部分。
3. **证据账本**：逐条记录主张、来源、发布日期、取证位置、核验状态、可视化方式与授权状态。
4. **旁白与主张映射**：每句重要旁白对应证据账本条目，不出现无来源的精确事实。
5. **视觉职责表**：为每个片段和镜头标明素材类型、信息职责、来源或生成方式，以及是否需要后期可控图形层。
6. **生成与质检记录**：模型、参数、Prompt、素材映射、任务 ID、失败原因、重生成次数和逐项检查结果。

## 叙事设计

根据议题选择结构，不机械套用固定段落。完整作品通常需要解决以下问题：

- **现实锚点**：用一个可验证的现场、物件、数字、文件或矛盾让问题成立。
- **核心问题或判断**：尽早说明视频要解释什么，不用模糊悬念拖延主题。
- **必要背景**：只补足理解当前论点所需的历史、制度与地理关系。
- **机制与因果链**：逐步说明谁做了什么、通过什么机制、造成什么变化。
- **规模与比较**：用经过核实的数据、时间变化或基准对象说明重要性。
- **地面后果**：回到具体人物、地点、企业、行业或公共生活，展示结构如何影响现实。
- **反例与限制**：交代证据边界、替代解释和无法确定的部分。
- **结论与下一观察点**：回答开头问题，并说明接下来什么事实会改变判断。

旁白采用清楚、直接、可核查的分析语言。避免连续堆砌数字、抽象名词和无主语判断；使用因果词时必须有证据支持。Visual Journalism 不继承 Animated Explainer 的固定字数目标；按内容密度、画面阅读时间和目标音色实测每个片段能否说完。

## 视觉语法

先为镜头指定唯一的主要信息职责，再选择媒介。一个镜头可以包含多层元素，但不得同时竞争多个主要结论。

- **证据**：现场实拍、档案影像、原始文件、已核验照片或网页截取，回答“凭什么这样说”。
- **定位**：地图、卫星图、时间轴或空间剖面，回答“在哪里、何时、彼此多远”。
- **机制**：解释性动画、流程、关系图或对象运动，回答“如何发生”。
- **规模**：折线、柱形、比例、计数和前后对比，回答“多大、多少、变化多快”。
- **后果**：人物、街道、工厂、市场或环境的具体变化，回答“这对现实意味着什么”。
- **不确定性**：范围、情景分支、缺失数据或相互冲突的证据，回答“我们还不知道什么”。

在地图与地面现实之间有意识地往返：地图建立结构，现场素材恢复真实尺度。只在内容需要时使用主持人或专家；他们负责解释、见证或提供判断，不作为缺少视觉证据时的填充画面。

## 专属生产流程

1. **锁定问题与截止时间。** 明确本片回答的单一核心问题、事实截止时间和地理范围。
2. **建立证据账本。** 先查原始和权威来源，再使用高质量二手报道；记录冲突、缺口和授权限制。
3. **形成论证图。** 从证据提炼主张、因果链、反例与不确定性；证据不足时缩小或改变结论，不用画面强化未经证实的说法。
4. **寻找视觉锚点。** 选择能直观承载核心矛盾的真实对象、空间关系、文件、数据变化或过程，作为全片反复返回的视觉中心。
5. **选择当前 Mode style。** 只展示 Visual Journalism 的候选或已验证 style；候选 style 必须明确待样片验证，也允许用户提供自定义文字风格。
6. **同步写旁白与视觉职责表。** 每段旁白同时指定对应证据和最合适的视觉媒介，不先写满旁白再用无关素材填空。
7. **规划来源与合成边界。** 区分可授权真实素材、生成镜头和后期可控图形层；地图、数字、日期、单位、来源和高密度文字默认不交给生成模型自由创作。
8. **编写并保存逐片段 Prompt。** 按[视频 Prompt 指南](video-prompt-guide.md)写明镜头职责、素材来源、可见变化和结束状态；精确图形层另列合成规格。
9. **先做代表性样片。** 首轮至少选择一个包含真实感镜头、地图或机制动画、图表或关键数字的片段，比较候选模型并完成内容质检，再决定是否批量生产。
10. **锁定音色并生成。** 正式有声生成前按共享音色指南选择内置音色或通过片段 1 新建音色；片段 1 与代表性样片可为同一片段，但必须同时通过声音和视觉确认。
11. **完成编辑与事实复核。** 合成准确文字、地图和图表，逐条复核证据账本，检查授权与必要披露，再交付剪辑。

## 地图规则

- 地图必须使用可核查的边界、比例、地点和时间版本。无法确认准确性时停止使用，不以风格化近似图替代事实地图。
- 出现中国地图时，必须使用符合中国官方标准地图规定的完整中国版图和边界表达；明确台湾属于中国，不得把台湾绘制或标注为独立国家或与中国无关的区域。
- 在使用生成模型前先确认它能否可靠满足地图要求。模型不支持、无法确认边界准确性或结果不符合要求时，立即放弃该生成地图并告知用户。
- 地图失败后不得自行切换模型、偷偷重试其他模型或使用近似地图。只有用户获知问题并明确选择新模型或替代方案后才继续。

## 进入生成前的质量门槛

以下任一情况存在时停止生成并报告：

- 核心问题、事实截止时间或主要结论仍不明确。
- 重要事实、数字、引语或因果判断没有对应证据账本条目。
- 事实、分析、预测和价值判断未被区分。
- 使用中的真实素材缺少来源、授权状态或必要署名信息。
- 地图边界、图表数据、日期、单位或数字语义尚未核实。
- 计划让生成模型自由生成密集正文、精确新闻页面、复杂表格或无法复核的地图。
- 镜头只有“新闻感”装饰，却不能说明它承担的证据或解释职责。
- 合成或生成的画面可能被误认为真实现场，但没有计划进行必要披露。

## 首轮样片验证

首轮优先比较 MiniMax M3 与 Seedance 2.0 Pro，但该选择只是宿主项目的测试路线，不代表通用默认模型。至少记录：

- 画内文字逐字准确率，以及数字、日期和单位准确率。
- 地图、图表和机制动画的语义正确性。
- 信息层级可读性与运动中的文字稳定性。
- 纪录片镜头的真实感，以及是否出现廉价素材库或广告质感。
- 旁白主张与画面证据是否一致。
- 失败任务、失败原因、重生成次数和人工合成需求。
- 每种素材的来源、授权、署名与披露是否完整。

样片经用户确认前，不把候选 style、模型、旁白密度、镜头节奏或合成方法标记为已验证规则。
