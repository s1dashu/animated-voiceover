# 人物参考图指南

## 人物数量规划

在旁白定稿后、生成任何参考图前，先通读完整讲稿和全部片段规划，建立全片人物清单。

- 人物参考图的数量由影片中的关键人物数量决定，不预设 1–3 人等固定范围，也不为凑数增加角色。
- 只有会跨镜头或跨片段重复出现，或在单个重要片段中必须保持稳定身份、需要被观众识别为同一人的角色，才计入关键人物并生成人物参考图。
- 同事、乘客、路人、顾客、士兵等只承担一次性功能时，作为没有固定身份的群演处理，不生成人物参考图。
- 影片需要几个关键人物，就为几个人分别生成独立人物参考图；不得把多个不同人物合并在同一张人物参考图中。
- 先输出并保存“人物—身份职责—辨识特征—出现片段—参考图状态”对应表；人物数量和名单经用户确认后再生成。

## 人物参考图规格

每个主要人物生成一张独立人物参考图：

- 一张图中只出现同一个人物的两个全身形象：正面位于左侧，背面位于右侧；两者等比例、同服装、同发型、同材质、同姿态高度。
- 使用纯白背景、均匀正面照明和自然中性站姿，不加入场景、道具、文字、标签、边框、网格、投影或装饰。
- 正面形象必须无遮挡，眼睛、眉毛、鼻子、嘴、脸型、发际线和发型清楚可辨；背面形象必须清楚展示后脑、发型背面、肩背轮廓、服装背面和鞋履。
- 该图只负责该人物的身份、相貌、头身比例、体态、服装与材质，不承担场景构图职责。

Seedance 官方指南提示，多视图人物素材可能造成主体混淆、ID 漂移或重复人物。本 skill 仍按用户确认的“正面＋背面同图”流程执行；提交视频时必须把整张图明确绑定为同一个人物，片段 1 若出现换脸、同款分身或双胞胎效果，保留任务与素材记录并向用户报告，不静默换图或掩盖问题。

动画视频不生成独立场景参考图、画风参考图或风格参考图。场景内容和视觉风格在每个片段的视频 Prompt 中按该片段的叙事需求具体描述。

## 输入视频模型时的图片指代

按实际连接顺序编号，只连接当前片段需要保持稳定身份的关键人物参考图；每个视频节点都根据自己的真实输入重新核对编号。

只有一个主要人物时，参考素材职责使用：

```markdown
参考图1为青年主角的人物参考图。将参考图1中短而蓬松的深棕发、灰绿色短外套的青年定义为“青年主角”。视频中的青年主角参考图1的人物形象。
```

存在多个关键人物时，按连接顺序逐个定义：

```markdown
参考图1为人物甲的人物参考图，参考图2为人物乙的人物参考图。将参考图1中具有[稳定特征]的人物定义为“人物甲”，将参考图2中具有[稳定特征]的人物定义为“人物乙”。视频中的人物甲参考图1的人物形象，人物乙参考图2的人物形象。
```

遵循以下约束：

- 用 2–3 个稳定静态特征定义每个主体，并在全部镜头中持续使用同一角色标签。
- 每次提到已定义的主要人物时都使用其固定标签，不改用“他”“她”“那个人”等可能混淆的指代。
- 人物参考图编号只来自当前节点真实连接顺序；不得引用未连接素材，也不得沿用其他片段的旧编号。
- 没有固定形象的群演不绑定人物参考图。Prompt 直接说明群演与关键人物使用相同的视觉媒介、造型语言和渲染体系，同时不得复制关键人物的具体脸、发型和服装。
- 每个片段根据具体内容写清场景地点、时代、空间结构、天气、道具、材质、色彩、光线和摄影方式；不同片段可以更换全部场景内容，只需保持所选 style 的稳定视觉语言。
