# 共享视频生成 Prompt 指南

## 适用范围

本指南只维护跨 Mode 通用的视频生成 Prompt 规则：参考素材职责、人物身份、场景状态、动作、摄影、连续性、落盘和提交检查。选题、旁白结构、故事节拍、解释性画面、现实素材编排和音乐时间轴等内容以当前 [Mode](../SKILL.md#mode-选择与路由) 文件为准。

使用 Seedance 时同时完整读取 [Seedance 2.0 官方提示词指南](official-seedance-2.0-prompt-guide.md)。处理循环动作、重复运镜或切镜僵硬时，再读 [社区导演实践笔记](community-directing-notes.md)。具体参数、输入限制与节点执行方式以用户选定的 [CLI 工具](../SKILL.md#执行工具路由) 文档和实时 schema 为准。

## 写作前准备

为当前片段确认：

1. 当前 Mode 的内容任务和本片段的叙事职责。
2. 已确认的 style 与当前片段所需的具体场景。
3. 需要实际连接的人物、音频、图片或视频参考，以及它们的真实连接顺序。
4. 开场时各人物、道具与环境的状态，以及结尾必须发生的可见变化。
5. 哪些空间、服装、道具、动作和光线关系需要与相邻镜头或片段连续。
6. 用户或宿主项目已确认的声音、字幕、背景音乐和画内文字要求。

内容文本尚未定稿时不写最终 Prompt。不在分镜阶段悄悄改写旁白、对话、歌词或事实命题。

## 参考素材职责

- 按当前节点的实际连接顺序编号，不沿用其他片段或其他平台的旧编号。
- 在 Prompt 开头逐个说明素材是什么、只负责什么，不让人物参考图变成场景或构图参考。
- 只连接当前片段实际需要的素材。不为通过 schema 校验接入无关视觉参考。
- 对每个关键人物使用固定标签和 2–3 个稳定静态特征；在同一 Prompt 中不随意改用“他”“那个人”等模糊称呼。
- 音频只承担音色参考时，明确它不提供本片段语义；当前片段的准确声音内容只来自当前 Prompt 内的定稿文本。

## Prompt 内容顺序

按以下顺序组织，没有对应内容时跳过：

1. 参考素材职责和人物身份定义。
2. 声音语言、音色来源、表达方式和准确文本。
3. 当前片段的具体地点、时代、空间、天气、材质、色彩、光线和渲染语言。
4. 只在多镜头反复拍摄同一可识别地点且连续性重要时，写必要的空间连续性。
5. 按顺序写每个镜头的起始构图、主体、可见变化、机位、运镜、结束状态和切镜条件。
6. 只写用户、Mode 或项目明确需要的额外约束。

## 镜头可执行性

每镜都写清：

1. 主体是谁或什么，位于画面哪里、朝向哪里。
2. 主体所在场景与起始状态。
3. 哪个执行者以什么方向、路径、速度和幅度完成动作。
4. 动作对其他人物、物体或环境产生什么可见反馈。
5. 镜头结束时落到什么新画面状态。
6. 摄影机的起始位置、高度、朝向、移动路径、停止位置和结束景别。

区分画面左右与人物自身左右。使用复合运镜时写清阶段顺序与衔接点。一条动作无法在当前片段内完成时，缩短动作链或明确跨镜承接，不用“慢慢变化”“逐渐出现”等没有落点的词。

## 连续性与切换

- 相邻镜头默认直接硬切。新地点、新时间或重现画面从完整定义的新场景开始，不写擦除、形变、融化、线条延伸、颜色接力或其他装饰性转场来掩盖切镜。
- 只有连续镜头本身承担明确叙事职责时才例外，例如必须保持动作空间关系的长时间打斗、追逐或精心编排的长镜头；此时直接写连续调度，不把它包装成花哨转场。
- 只有多个镜头反复拍摄同一空间时，才定义空间形状、门窗、大型物体、道具排列与光源方向。
- 独立场景、并列案例与跨时空蒙太奇分别定义新的起始状态，不强行建立无关的空间承接。
- 只在下一镜继续同一条动作时，明确承接上一镜已完成的状态。
- 相邻镜头必须提供新信息、新动作或新后果，不重启已经完成的推近、抬头、起身、开门或聚焦动作。
- 只有重复本身具有明确叙事意义时才重置状态，并在 Prompt 中写明这是有意重复。

## 参数与 Prompt 边界

- 时长、比例、分辨率、声音开关、数量和输入模式只通过当前 CLI 参数传递，不在创作 Prompt 中重复。
- 不将“片段 1”、字数、审稿标签、编辑理由或不存在的参考素材交给模型。
- 不默认堆叠“无字幕、无 Logo、无水印、不做口型”等项目未要求的负面词。
- 不用“高级、震撼、史诗、唯美”等空泛质量词代替可执行的构图、材质、光线和动作。
- 如果历史输出出现画面内部黑边，使用正向构图要求：“所有镜头采用满幅画面，场景与背景完整覆盖整个可见构图区域。”

## 落盘与提交检查

- 每个片段 Prompt 单独保存为 Markdown 文件；按宿主项目规则命名，没有规定时使用 `<作品目录>/production-docs/片段01.md`、`片段02.md`……
- 每个文件至少记录 Mode、作品标题、片段编号、style、实际参考素材职责、定稿声音内容和完整 Prompt。
- 编写顺序、文件编号、文本片段编号和后续视频节点编号保持一致。
- 提交前按当前 Mode 的质量门槛与本指南逐项核对，并确认所有引用素材都已真实连接。
