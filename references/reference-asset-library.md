# 内置参考资产库

## 使用原则

本清单是随本 skill 分发的内置音色与历史图像资产的公开目录。动画视频标准流程只展示和选择内置音色；人物参考图根据当前影片的关键人物单独规划与生成，不展示或使用场景／画风参考图。

表中的相对路径均以本文件所在的 `references/` 目录为起点。选择资产后先核对文件存在、媒体规格和 SHA-256；文件缺失或哈希不符代表 skill 安装损坏，应明确报错并停止，不得扫描作品目录寻找同名文件作为替代。

## 扩充边界

新生成的参考默认属于当前作品，不自动进入公开库。只有用户明确确认其可跨作品复用并纳入公开 skill 后，才把标准化媒体放入 `assets/reference-library/`，更新本清单、哈希和对应指南。候选、失败版本、生成 Prompt、质检记录以及私有平台工作区、画布、节点和任务 ID 均保留在宿主项目，不写入本公开目录。
