# 内置音色库

## 使用原则

本清单是随本 skill 分发的内置音色公开目录。人物参考图根据当前影片的关键人物单独规划与生成；视觉风格仅由当前 Mode 的 `styles/` 中文字规则与当前片段 Prompt 定义，不使用场景图或画风参考图。

表中的相对路径均以本文件所在的 `references/` 目录为起点。选择资产后只确认文件存在且扩展名为 `.wav`，随后通过目标平台上传并尝试生成；不例行检查 SHA-256、编码、采样率、位深或声道。平台拒绝时保留并返回实际错误，再针对该错误诊断。文件缺失时明确报错并停止，不得扫描作品目录寻找同名文件作为替代。表中的媒体规格与 SHA-256 只用于资产来源和版本追踪，不是每次使用前的强制校验。

## 扩充边界

新生成的音色默认属于当前作品，不自动进入公开库。只有用户明确确认其可跨作品复用并纳入公开 skill 后，才把标准化音频放入顶级 `voices/`，更新本清单、哈希和对应指南。候选、失败版本、生成 Prompt、质检记录以及私有平台工作区、画布、节点和任务 ID 均保留在宿主项目，不写入本公开目录。
